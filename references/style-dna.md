# SYC 风格 DNA 详解

来源：《我的女友景甜》，孙宇晨，2026年8月27日

## 句子层面

### 句长分布
- 短句（<10字）：约40%，集中在情绪高峰
- 中句（10-30字）：约45%，叙事主体
- 长句（>30字）：约15%，用于细节展开

### 典型句式
1. **对话句**：`她说，行了。` / `我说好。`
2. **数字句**：`一颗卵子的重量，三点五微克。`
3. **行为句**：`她把我的手放在她腿上，一根一根磨。`
4. **收束句**：`什么都没有发生。`

## 段落层面

### 段落结构
- 开头：场景/时间/地点锚定
- 中间：行为细节展开（慢写）
- 结尾：收束句（不超过15字）

### 节奏控制
- 重要场景：慢写，细节密集
- 过渡/决定：快写，一句带过
- 对话：极简，不解释

## 全文层面

### 主题句
"什么都没有发生" 出现3次，成为全文主题。

### 时间结构
非线性，但有清晰的时间锚点：
- 2007年（北大）
- 2011年（羽绒服/《战国》）
- 2026年1月2日（求婚）
- 第八天（电话）

### 数字密度统计
全文约6000字，精确数字出现约35次，平均每170字一个数字锚点。

## 情感机制

### 冰山比例
- 水面上（可见）：行为、数字、对话
- 水面下（隐藏）：爱、痛、执念、失落

### 情感载体清单
| 情感 | 载体 |
|---|---|
| 19年执念 | 那张QQ图片，每次换设备都导过去 |
| 爱 | 磨指甲，一根一根，快一个小时 |
| 失落 | 指甲现在还是磨人的 |
| 心碎 | 数心跳，一分钟六十几下，和平时没有区别 |
| 不舍 | 删了图，第二天又找回来 |

## 语言特征

### 用词偏好
- 数字：中文写法（三点五，不是3.5）
- 货币：美元/人民币明确区分
- 时间：精确到天（第八天，2026年1月2日）
- 距离：精确（九千五百公里）

### 禁用词汇
- 情绪形容词：美丽、深沉、复杂、温柔
- 情绪名词：爱、痛、失落、遗憾、思念
- AI套话：不禁、令人、深深地、意识到
- 标点：感叹号、省略号（表情绪时）

## 参照文学传统

- **海明威冰山理论**：七分之六在水下
- **新新闻主义**：精确细节，场景重建
- **零度写作（罗兰·巴特）**：情感中性，让事实说话
- **村上春树**：数字锚点，物件承载情感
